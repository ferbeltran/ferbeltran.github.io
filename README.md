# Kaiju — landing page

Static page (index.html + img/), published with GitHub Pages. Links (Gumroad, download) are at the top of the script in index.html; the contact address is put together there too.

The scroll effects use `scrollcraft.js` / `scrollcraft.css`, copied unmodified from the scroll-craft skill (github.com/nateherkai/scroll-craft, MIT license). Page-specific behavior (the mode keys, the "bring it whole" board, the city) lives in the script at the bottom of index.html.
